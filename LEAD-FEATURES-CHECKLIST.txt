HOW TO OPEN LEADS
-----------------
[ ] Left sidebar → CRM → Leads
[ ] Or press Cmd + K (Mac) / Ctrl + K (Windows) and search a lead name


ADD A NEW LEAD
--------------
[ ] Click orange "Add Lead" button on top right
[ ] Fill customer name (required)
[ ] Add phone, email, company (optional)
[ ] Pick where enquiry came from (WhatsApp, Phone, Website, etc.)
[ ] Pick lead status (New, Contacted, Qualified, etc.)
[ ] Pick Hot / Warm / Cold / No Status
[ ] Pick service type (Package, Flight, Hotel, Visa, Bus)
[ ] Pick B2C or B2B
[ ] Add travel date and destinations (e.g. Mumbai-Dubai)
[ ] Add number of adults, children, infants
[ ] Add estimated trip value in INR
[ ] Set next follow-up date and time
[ ] Assign to a sales person
[ ] Write requirement / notes
[ ] Click Create — you should go to that lead's detail page
[ ] New lead gets auto number like Q/26/1234567


LEADS LIST PAGE (MAIN TABLE) — LIKE HELLO GTX
---------------------------------------------
[ ] See table with columns: Query date, Customer, Pax/Type, Description, Travel date, Destinations, Proposal, Lead stage
[ ] See "Total records found" count on the right
[ ] Search box works (name, phone, query number, destination)
[ ] Filter by assignee (All, Unassigned, My leads, or pick a person)
[ ] Page numbers work at bottom (20 leads per page)

TEMPERATURE TABS (HOW URGENT IS THE LEAD?)
------------------------------------------
[ ] All tab shows every lead
[ ] Hot tab — urgent leads (red)
[ ] Warm tab — medium interest (orange)
[ ] Cold tab — low priority (blue)
[ ] No Status tab — not marked yet
[ ] Each tab shows count in brackets e.g. Hot (3)

PROGRESS TABS (WHERE IS THE LEAD IN THE SALES PROCESS?)
-------------------------------------------------------
[ ] In Progress — leads still being worked on
[ ] Recent — leads added in last 7 days
[ ] Confirmed — qualified leads
[ ] Converted — won / became customer
[ ] Lost / Trash — lost leads
[ ] Overall — everything
[ ] Each tab shows count in brackets

BULK ASSIGN (ASSIGN MANY LEADS AT ONCE)

[ ] Tick checkbox on left of one or more leads
[ ] Pick a sales user → click orange Assign
[ ] Pick an ops user → click Assign
